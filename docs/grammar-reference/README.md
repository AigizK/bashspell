# Справочники по грамматике башкирского языка

Локальная копия двух справочников с сайта Института истории, языка и литературы
УФИЦ РАН:

- [Грамматика современного башкирского литературного языка](gram/gram.html)
  — 444 доступные HTML-страницы;
- [Алгоритмическая грамматика словоизменения башкирского языка](algram/algram.htm)
  — 8 HTML-страниц.

Страницы сохранены в исходной кодировке и с исходной структурой каталогов,
поэтому относительная навигация работает локально. Полный перечень URL, размеры
и SHA-256 файлов находятся в [manifest.json](manifest.json).

Две ссылки в исходном справочнике отсутствуют на сервере и возвращают 404:

- `gram/morphol/prilag/affi.htm`;
- `gram/morphol/prilag/adektiv.htm`.

Служебные ссылки Microsoft Word на `*.files/filelist.xml` также возвращают 404
на исходном сервере. Эти метаданные не участвуют в отображении страниц и в
локальную копию не включены.

Обновить зеркало можно командой из корня проекта:

```bash
python3 tools/download_grammar_reference.py
```
