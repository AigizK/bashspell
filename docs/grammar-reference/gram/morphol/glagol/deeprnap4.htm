В сочетании с императивом на -һын/-һен и формой будущего времени на -р, -ыр/-ер грамматикализованная полифункциональная форма деепричастия тип, способная организовать придаточную часть целевого сложноподчиненного предложения, имеет регулярное целевое значение: Һиңә килдем әйтермен тип ҙур һүҙ (М. Кәрим) 'Я к тебе пришел, чтобы сказать веское слово'; Мин был кооператив квартирамды, балаларым ошонда иркенләп йәшәһен тип, һатып алғайным 'Я эту кооперативную квартиру купил с тем, чтобы дети мои жили в ней, не испытывая тесноты'.
