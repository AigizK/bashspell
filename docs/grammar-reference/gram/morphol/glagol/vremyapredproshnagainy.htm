Предпрошедшее определенное время (форма на -ғайны)

Предпрошедшее определенное время образуется при помощи афф. -ғайны/-гәйне, который присоединяется к глагольной основе.

Ед. число                                                                   Мн. число

1 л. алғайным 'я уже (раньше) взял'                      алғайныҡ 'мы уже (раньше) взяли

2 л. алғайның 'ты уже (раньше) взял'                    алғайнығыҙ 'вы уже (раньше) взяли

3 л. алғайны 'он уже (раньше) взял'                      алғайнылар 'они уже (раньше) взяли

Данная форма относительного времени означает очевидное действие в прошлом, которое произошло раньше другого действия. Это другое действие может быть выражено по разному: либо оно передается другими формами прошедшего времени, либо при помощи контекста, а также придаточными предложениями времени: Сәғит сыҡҡанда, йылҡысы, ҡороғон эргәһенә ҡуйып, тәрән йоҡоға киткәйне (А. Таһиров) 'Когда Сагит вышел во двор, коневод уже спал, положив рядом с собой свой аркан'; Айбулат бөгөн дә, Рәхимә менән һүҙ көрәштереүсең кәрәкһеҙ икәнен уйлап, өйҙән сығып китергә уйлағайны (Һ. Дәүләтшина) 'Айбулат, хорошо знавший бесполезность спора с Рахимой, решил выйти из дома'; Айсыуаҡ килеп еткәндә, больница тирәһендә йән әҫәре ҡалмағайны (Т. Килмөхәмәтов) 'Когда Айсувак приехал в больницу, там уже не было ни одной живой души'; Заһит ревкомдан сыҡҡанда, буран көндөҙгөгә ҡарағанда ла көсәйгәйне (Я. Хамматов) 'Когда Загит вышел из ревкома, уже шел сильный буран'.
