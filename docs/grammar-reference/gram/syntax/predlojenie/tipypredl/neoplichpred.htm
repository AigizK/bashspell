НЕОПРЕДЕЛЕННО-ЛИЧНОЕ ПРЕДЛОЖЕНИЕ

Неопределенно-личное предложение с намеренно устраненным подлежащим служит для обозначения действия, осуществление которого обобщенно приписывается неопределенным лицам, хотя формально функцию сказуемого неопределенно-личного предложения и выполняет 3-е лицо мн. числа изъявительного и условного наклонений: Шакир ағайҙы бер ауыҙҙан председатель иттеләр (Д. Юлтый) 'Дядю Шакира единогласно избрали председателем'; Наградаларҙы йәшкә ҡарап бирмәйҙәр, оҙаҡ йәшәгән өсөн генә хөрмәт күрһәтмәйҙәр (М. Кәрим) 'Наградами отмечаются не просто, по возрасту, почестями окружаются не просто за долголетнюю жизнь'; Колхоз башлығын ашлығына ҡарап һынайҙар (посл.) 'О руководителе колхоза судят по хлебу, выращенному артелью'.
